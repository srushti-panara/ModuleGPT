# 🎓 ModuleGPT - AI Module & Roadmap Generator

> Learn smarter with AI-generated modules, personalized roadmaps, progress tracking, and gamified learning experiences.

---

## 🚀 Overview

ModuleGPT is an AI-powered learning platform designed to help students and self-learners generate structured study modules and complete learning roadmaps instantly using Gemini AI.

The platform combines AI-generated educational content with gamification, streak tracking, badges, progress analytics, customizable themes, and module management to create an engaging and interactive learning experience.

---

## ✨ Features

### 🧠 AI Module Generator
Generate detailed learning modules with:
- Learning objectives
- Core concepts
- Practical applications
- Exercises & practice tasks
- Knowledge checks
- Quick revision notes

### 🗺️ AI Roadmap Generator
Create complete step-by-step learning roadmaps including:
- Beginner → Advanced paths
- Mindmaps / Flowcharts
- Milestones
- Projects & practice
- Success metrics

### 🏆 Gamified Learning System
- Daily learning streaks
- Login streaks
- Achievement badges
- Completion tracking
- Progress analytics

### 🎨 Personalized Experience
- Dark / Light mode
- Adjustable font sizes
- User profile customization
- Saved learning modules
- Search history management

### 📚 Learning Management
- Save generated modules
- Open full module view
- Track completion status
- Delete & manage content
- Persistent local storage

## ⚙️ Installation
Clone the repository: <br>
git clone https://github.com/srushti-panara/ModuleGPT.git <br>
cd ModuleGPT <br>

---

## Install dependencies:
pip install -r requirements.txt

## Create a .env file:
GEMINI_API_KEY = your_api_key_here

## Run the application:
streamlit run app.py

## 🔐 Environment Variables
| **Variable**	      | **Description**          |
|------------------------------------------------|
| GEMINI_API_KEY	    | Your Gemini API key      |

Get your API key from: <br>
https://aistudio.google.com/ <br>
